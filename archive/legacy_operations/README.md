# Archived legacy operations

These files formed the pre-canonical daily update, Telegram report, status
display, standalone stream listener, and old Quick Sync launcher.

They were replaced by `nfl_daily_update.py`,
`telegram_notification_center.py`, `health_check.py`, the embedded dashboard
stream, and `bot_launcher.py`. Production workflows do not import or execute
this directory. Runtime logs and historical registries remain in their
original locations.
