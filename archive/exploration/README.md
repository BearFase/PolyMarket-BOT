# Archived exploration scripts

These scripts were one-off API probes, wallet investigations, settlement
checks, and data experiments used while the current platform was being built.
They were retired because no production launcher, scheduler, Flask route, or
active module imports them. Their useful findings were incorporated into the
canonical NFL registry, real-position synchronizer, Game Flow, or research
pipeline.

They are preserved for provenance. They are not production entry points and
may refer to obsolete endpoints, identities, assumptions, or file locations.
No historical runtime data was moved or deleted during archival.
